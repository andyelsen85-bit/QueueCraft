name: Milestone creation access
description: User's standing requirement for cross-department milestone creation.

All members should be able to create milestones on all topics, even topics not linked to their own department.

**Why:** The user explicitly requested this access rule.

**How to apply:** Do not reintroduce department, role, creator, assignee, or collaborator requirements for milestone creation. This request concerns creation; it does not grant broader edit/delete or topic-management access, or remove scheduling and validation rules.
